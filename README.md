# Maulana Hidayatulloh — Portfolio

Portfolio static website dengan gaya Modern Tech, warna biru-putih, responsive untuk desktop/tablet/mobile.

## Struktur
- `index.html` — halaman utama
- `style.css` — styling dan responsive layout
- `script.js` — animasi reveal, mobile menu, scroll progress

## Cara menjalankan
Buka `index.html` langsung di browser, atau gunakan Live Server di VS Code.

## Foto profil
Foto profil sudah dipasang sebagai `profile.png` dan digunakan pada bagian hero.
